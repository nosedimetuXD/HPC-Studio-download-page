Overview & Architecture

#

Traditional computational materials science relies on fragmented tools: generic text editors for writing Fortran namelists, manual terminal SSH sessions for submitting jobs, third-party desktop tools for crystal visualization, and manual log grep-ing for diagnosing convergence failures.

HPC Studio unifies this workflow into a single, high-performance developer environment built upon the rock-solid open-source foundation of Code OSS. It integrates domain-aware scientific linting, direct Slurm workload scheduling, real-time WebGL crystallography rendering, and autonomous AI agents through the Model Context Protocol (MCP).

Built on Code OSS 1.96 All your existing VS Code keybindings, color themes, snippets, and extensions (Python, C/C++, Fortran, GitLens, Remote-SSH) work out of the box in HPC Studio.

Core Architecture

HPC Studio separates the lightweight desktop GUI client from the heavy computational workload executing on supercomputer nodes:

Layer Component Primary Responsibility
Presentation Desktop Workbench TextMate grammar highlighting, 3D WebGL crystal viewer, Slurm activity bar, agent chat panel.
Remote Protocol SSH Daemon & Multiplexing Zero-overhead SSH channel via ControlMaster/ProxyJump, bidirectional file sync, tunnel forwarding.
Domain Engine QE & DFT Language Server AST validation for namelists (&CONTROL, &SYSTEM), cutoff cross-checks with UPF headers.
HPC Scheduler Slurm REST / CLI Adapter Interactive SBATCH generator, live squeue polling, dynamic partition node allocation.
Autonomous Layer Simulation Agent (MCP) Log monitoring, DFT charge-sloshing anomaly detection, automated parameter sweeps.

Installation

#

HPC Studio is packaged natively across all major desktop operating systems with self-updating capabilities and zero external runtime dependencies.

Linux (Debian / Ubuntu / Pop!_OS)

Download the official .deb package from GitHub Releases and install using apt or dpkg:

🐧 Terminal (bash)
Shell 
# Download official Debian package
wget https://github.com/nosedimetuXD/HPC-Studio/releases/download/v1.143.0/hpc-studio_1.143.0_amd64.deb

# Install HPC Studio and resolve dependencies
sudo apt update && sudo apt install -y ./hpc-studio_1.143.0_amd64.deb

# Launch the IDE
hpc-studio

Generic Linux Tarball (.tar.gz)

For systems without root access or running on enterprise distributions (RHEL, Rocky Linux, CentOS Stream):

📦 Standalone Tarball
Shell 
tar -xvf hpc-studio-linux-x64-1.143.0.tar.gz
cd hpc-studio-linux-x64
./bin/hpc-studio

macOS & Windows (WSL2)

macOS: Download the Universal .dmg or .zip. Drag HPC Studio into your /Applications folder. Both Apple Silicon (M1/M2/M3/M4) and Intel architectures are natively supported.

Windows via WSL2: We strongly recommend installing HPC Studio on your Windows host while running the HPC Studio remote agent inside your WSL2 Ubuntu distribution for optimal Linux supercomputing parity.

Remote Cluster SSH Setup

#

HPC clusters almost universally mandate connection through a secure bastion host or login gateway. HPC Studio includes native SSH tunnel multiplexing so you can edit remote simulation files and run Slurm commands seamlessly without continuous password prompts.

Configuring ~/.ssh/config

Add your cluster host definitions to ~/.ssh/config. HPC Studio automatically detects all hosts defined in this file and presents them in the Remote Explorer activity bar:

🔑 ~/.ssh/config
SSH Config 
# =========================================================================
# HPC Studio Remote Cluster Configuration
# =========================================================================

# 1. Bastion / Jump Host Gateway
Host hpc-gateway
    HostName gateway.supercomputer.ac.uk
    User quantum_user
    IdentityFile ~/.ssh/id_ed25519_hpc
    ServerAliveInterval 60
    ServerAliveCountMax 5

# 2. Compute Login Node (Accessible via ProxyJump)
Host hpc-cluster-login01
    HostName login01.internal.supercomputer.local
    User quantum_user
    ProxyJump hpc-gateway
    IdentityFile ~/.ssh/id_ed25519_hpc
    ControlMaster auto
    ControlPath ~/.ssh/sockets/%r@%h:%p
    ControlPersist 4h
    ForwardAgent yes
Pro Tip: ControlMaster Multiplexing Setting ControlPersist 4h allows multiple terminals, Slurm queue pollers, and file saves to reuse the existing encrypted SSH socket without re-authenticating every transaction.

  • Slurm Workload Manager: Local single-node queue running slurmd and slurmctld for testing submission scripts.

Quantum ESPRESSO Workflow

#

HPC Studio features full semantic intelligence for Quantum ESPRESSO input and output files (pw.x, cp.x, ph.x). It validates namelists, flags obsolete keywords, suggests optimal cutoff energies, and provides an interactive 3D crystal preview of your unit cell.

SCF & Relax Calculations

Below is an example of an optimized self-consistent field (SCF) input file for Silicon in the diamond structure (FCC lattice). As you type this in HPC Studio, IntelliSense automatically auto-completes available namelist keys and flags syntax errors:

⚛️ pw.scf.silicon.in
Fortran Namelist 
&CONTROL
  calculation   = 'scf'
  restart_mode  = 'from_scratch'
  prefix        = 'silicon'
  outdir        = './scratch/'
  pseudo_dir    = './pseudo/'
  verbosity     = 'high'
  tprnfor       = .true.
  tstress       = .true.
/

&SYSTEM
  ibrav         = 2                   ! Face-Centered Cubic (FCC)
  celldm(1)     = 10.26               ! Lattice parameter in Bohr (5.43 Å)
  nat           = 2                   ! Number of atoms in primitive basis
  ntyp          = 1                   ! Number of distinct atomic species
  ecutwfc       = 40.0                ! Kinetic energy cutoff for wavefunctions (Ry)
  ecutrho       = 320.0               ! Kinetic energy cutoff for charge density (Ry)
  occupations   = 'fixed'
/

&ELECTRONS
  conv_thr         = 1.0d-8          ! Convergence threshold for self-consistency
  mixing_beta      = 0.7             ! Charge density mixing factor
  diagonalization  = 'david'         ! Davidson iterative diagonalization
/

ATOMIC_SPECIES
  Si  28.0855  Si.pbe-n-kjpaw_psl.1.0.0.UPF

ATOMIC_POSITIONS (alat)
  Si  0.00000000  0.00000000  0.00000000
  Si  0.25000000  0.25000000  0.25000000

K_POINTS (automatic)
  6 6 6   1 1 1

UPF Pseudopotentials Library

Missing pseudopotentials cause over 60% of rookie DFT job crashes. HPC Studio solves this with an Integrated Pseudopotential Resolver:

  • Right-click any .UPF reference in your input file to inspect its header metadata (PAW vs. Ultrasoft vs. Norm-Conserving, exchange-correlation functional, valence electrons, suggested ecutwfc / ecutrho cutoffs).
  • Click "Fetch missing UPF from SSSP" to automatically download standard solid-state pseudopotentials directly into your cluster's pseudo_dir.

3D Crystal Viewer

Whenever you open a pw.x input file, HPC Studio activates the 3D Crystal View tab in the editor pane. Powered by high-efficiency WebGL:

  • Rotate, zoom, and inspect unit cells, supercells, and fractional atomic coordinates in real time.
  • Toggle periodic boundary conditions (1x1x1, 2x2x2, 3x3x3 replication).
  • Calculate interatomic bond distances and bond angles with a single click on any two atoms.
  • Export publication-quality raytraced PNGs directly to your project workspace.

Slurm Workload Manager

#

Slurm is the premier workload scheduler on top-500 supercomputers. HPC Studio bridges the gap between editing code and managing distributed HPC jobs through an integrated SBATCH generator, cluster resource explorer, and live queue telemetry.

Interactive SBATCH Generator

Instead of manually calculating MPI ranks and OpenMP thread masks, press Ctrl+Shift+P > Slurm: Generate Batch Submission Script. Choose your target partition, number of compute nodes, tasks per node, and walltime limit. HPC Studio outputs a hardened, production-ready script:

📊 submit_qe_job.slurm
Slurm / Bash 
#!/bin/bash
#SBATCH --job-name=qe_silicon_scf
#SBATCH --partition=standard
#SBATCH --nodes=2
#SBATCH --ntasks-per-node=16
#SBATCH --cpus-per-task=4
#SBATCH --time=02:00:00
#SBATCH --output=slurm-%j.out
#SBATCH --error=slurm-%j.err
#SBATCH --mail-type=END,FAIL

# 1. Load Scientific Modules on Cluster
module purge
module load intel/2023.2 mpi/openmpi-4.1.5 qe/7.3

# 2. Configure Hybrid MPI/OpenMP Environment
export OMP_NUM_THREADS=$SLURM_CPUS_PER_TASK
export OMP_PLACES=cores
export OMP_PROC_BIND=close

# 3. Create Scratch Directory for Temporary Files
export SCRATCH_DIR="/tmp/scratch_${SLURM_JOB_ID}"
mkdir -p $SCRATCH_DIR

echo "Starting Quantum ESPRESSO job at $(date)"
echo "Running on $SLURM_NNODES nodes with 32 total MPI ranks and $OMP_NUM_THREADS OpenMP threads/rank"

# 4. Launch pw.x with MPI process binding
srun --mpi=pmix pw.x -nk 4 -in pw.scf.silicon.in > pw.scf.silicon.out

echo "Completed simulation with exit code $? at $(date)"

Cluster Queue Monitoring

The Slurm Explorer in the Activity Bar displays real-time telemetry from your cluster:

  • Live Jobs: View status (RUNNING, PENDING, COMPLETING, FAILED), elapsed walltime, priority ranking, and allocated compute nodes.
  • One-Click Cancellation: Cancel runaway jobs or hung calculations with scancel directly from the UI.
  • Output Log Streaming: Click any active job to stream its slurm-%j.out log file with automatic auto-scroll and error highlighting.

MPI / OpenMP Optimization

Quantum ESPRESSO supports multidimensional parallelization:

  • Image parallelization (-ni): For NEB reaction barrier scans.
  • k-point pool parallelization (-nk): Distribute k-point groups across disjoint MPI communicators for near-linear scaling.
  • Plane-wave band parallelization (-nb): Efficient scaling for large metallic supercells.

Simulation AI Agents

#

HPC Studio pioneers the application of Autonomous AI Simulation Agents in high-performance computing. Rather than functioning as generic chatbots, these agents run on the Model Context Protocol (MCP), connecting reasoning models directly to domain-specific scientific tools, cluster schedulers, and output logs.

Convergence Diagnostics

When an SCF calculation stalls or oscillates (charge sloshing), the agent inspects the tail of pw.x output in real time and provides an actionable diagnosis:

Agent Anomaly Detection: Charge Sloshing Observed The agent detected negative charge density oscillations across iteration #42. Suggested fix: reduce mixing_beta from 0.7 to 0.3 and switch diagonalization to 'cg'. Click [Apply Diff & Resubmit to Slurm] to automate the fix.

Automated Parameter Sweeps

Instruct the simulation agent: "Perform an energy cutoff convergence sweep from 30 Ry to 80 Ry in steps of 10 Ry on Silicon and plot total energy vs. ecutwfc."

1
Template Generation

The agent generates 6 input variations with varying ecutwfc values.

2
Batch Array Submission

The agent submits a Slurm job array (--array=1-6) to your remote cluster.

3
Automated Synthesis & Plotting

Upon completion, the agent parses total ground-state energies, verifies convergence within 1 mRy/atom, and renders an interactive SVG plot.

API & Extensibility

#

HPC Studio inherits the standard Visual Studio Code Extension API while exposing specialized high-performance scientific hooks under the hpc namespace.

Custom Language Grammars

HPC Studio ships with built-in TextMate grammars for Quantum ESPRESSO, Slurm batch directives, VASP (INCAR/POSCAR/KPOINTS), and LAMMPS input decks:

  • source.quantum-espresso: Highlights namelists, cards, and scientific constants.
  • source.slurm: Highlights #SBATCH pragmas with auto-validation of flag arguments.
  • source.cif: Crystallographic Information File syntax highlighting.

Extension API

You can write custom extensions in TypeScript or JavaScript. Access the HPC Studio cluster manager through the API:

📜 extension.ts
TypeScript 
import * as vscode from 'vscode';
import { hpc } from 'hpc-studio-api';

export function activate(context: vscode.ExtensionContext) {
  const submitCmd = vscode.commands.registerCommand('myPlugin.submitDFT', async () => {
    const cluster = await hpc.clusters.getActiveCluster();
    if (!cluster) {
      vscode.window.showErrorMessage('No active HPC cluster connected.');
      return;
    }

    const job = await cluster.slurm.submit({
      scriptPath: 'submit_qe_job.slurm',
      nodes: 2,
      tasksPerNode: 16
    });

    vscode.window.showInformationMessage(`Job ${job.id} submitted to ${cluster.name}!`);
  });

  context.subscriptions.push(submitCmd);
}

FAQ & Troubleshooting

#
Ensure that you have generated a modern Ed25519 key pair (ssh-keygen -t ed25519) and copied your public key to both the bastion host and the internal cluster login node. In your ~/.ssh/config, add ServerAliveInterval 60 and ServerAliveCountMax 5 to prevent aggressive supercomputer firewalls from severing idle SSH sessions.
SCF non-convergence in Quantum ESPRESSO typically stems from three causes:
  1. Charge sloshing: In small band-gap or metallic systems, reduce mixing_beta to 0.2 - 0.3 in &ELECTRONS.
  2. Unsuitable smearing: If your system is metallic, set occupations = 'smearing', smearing = 'mv' (Marzari-Vanderbilt), and degauss = 0.02.
  3. Diagonalization algorithm: Switch from Davidson to Conjugate Gradient (diagonalization = 'cg').
Yes! HPC Studio is designed for national laboratory environments with air-gapped high-security networks. You can download the offline standalone .tar.gz bundle and the offline .vsix extension packages without needing active internet access.
When compiling or loading Quantum ESPRESSO built with NVIDIA NVHPC SDK (OpenACC / CUDA), set #SBATCH --gpus-per-node=4 in your Slurm script and launch pw.x with one MPI task per GPU (e.g. srun -n 4 pw.x ...). HPC Studio's SBATCH Generator automatically detects available NVIDIA A100/H100/H200 partitions and configures GPU affinities.
