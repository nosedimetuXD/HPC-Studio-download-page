Core Architecture

Engineered Specifically for High-Performance Science

Traditional code editors treat scientific clusters like normal web servers. HPC Studio bridges raw compute with modern developer ergonomics.

⚛️

Quantum ESPRESSO & Ab Initio Modeling

First-class language intelligence for PWscf, PHonon, CP, and Wannier90. Get real-time namelist validation (&CONTROL, &SYSTEM, &ELECTRONS), auto-completion for over 400 QE parameters, and live total energy convergence graphs as your calculation runs.

  • Automatic Pseudopotential UPF / PSLibrary schema validation & cutoff suggestions
  • Live SCF, Relax, and VC-Relax step convergence visualization
  • Band structure and Density of States (DOS) interactive plotting
🖥️

Supercomputing & Slurm Queue Manager

Direct integration into Slurm, PBS Pro, and SGE workload managers. Inspect node topology, track core allocations, submit jobs with a single click, and stream log outputs seamlessly over SSH.

  • Visual Slurm queue dashboard (squeue / sinfo / scontrol)
  • Instant #SBATCH syntax linting & walltime checks
  • Automated SSH tunnels and remote environment forwarder
🔮

Interactive 3D Crystal & Molecular Visualizer

Inspect atomic coordinates, unit cells, and molecular orbitals directly in your editor viewport. Powered by lightweight WebGL with full support for .cif, .xyz, .pwi, and .pwo formats.

  • Unit cell replication (supercells 2x2x2, 3x3x3)
  • Real-time atomic displacement & phonon mode animation
  • Direct bond length & angle measurement tools
🤖

Scientific AI Agents & Built-in MCP Tools

Powered by Google DeepMind Antigravity and Model Context Protocol. AI assistants equipped with specialized scientific tools to diagnose SCF non-convergence, recommend k-point grids, and optimize MPI task distribution.

  • 9 built-in MCP tools for Slurm, Quantum ESPRESSO, and CIF parsing
  • Diagnostic agent for SCF oscillations and density mixing adjustments
  • Autonomous parameter tuning workflows
📦

Quantum Mobile & VirtualBox Preset

Zero-configuration environment for computational materials education. Built-in presets connect seamlessly to local Quantum Mobile virtual machines (127.0.0.1:2222) or remote cloud clusters with preloaded toolchains.

  • One-click connection to standard Quantum Mobile VMs
  • Preconfigured pseudopotential paths & MPI profiles
  • Reproducible computational science benchmarks
