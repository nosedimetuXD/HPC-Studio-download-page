# HPC Studio — Official Website & Documentation Portal

The official landing page and documentation portal for **HPC Studio**, the scientific IDE engineered for supercomputing, Quantum ESPRESSO, and autonomous AI simulation agents. Built on Code OSS.

## 🚀 Live Site Navigation
- **Home**: [`/`](https://nosedimetuxd.github.io/HPC-Studio-download-page/) — Download matrix (Linux .deb, macOS DMG, Windows WSL2), features overview, and architecture breakdown.
- **Documentation**: [`/docs/`](https://nosedimetuxd.github.io/HPC-Studio-download-page/docs/) — 2-column documentation portal with tutorials, Quantum ESPRESSO guide, Slurm SBATCH wizard, and MCP simulation agents.
- **Features**: [`/features/`](https://nosedimetuxd.github.io/HPC-Studio-download-page/features/) — Detailed breakdown of core scientific capabilities.
- **Extensions**: [`/extensions/`](https://nosedimetuxd.github.io/HPC-Studio-download-page/extensions/) — Marketplace showcase for ab initio simulation and supercomputing extensions.
